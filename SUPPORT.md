# Support

Thank you for using Tempo Pomodoro. Here is how to get help:

## Documentation

- [README.md](./README.md) — setup, configuration, and usage
- [CONTRIBUTING.md](./CONTRIBUTING.md) — how to contribute
- [CHANGELOG.md](./CHANGELOG.md) — release history

## Getting Help

- **Bugs and feature requests**: open an issue using the
  [issue templates](https://github.com/undefined-art/pomodoro/issues/new/choose).
- **Questions**: open an issue labelled `question`.

## Security

For security vulnerabilities, follow the process in
[SECURITY.md](./SECURITY.md). Do **not** report security issues publicly.
